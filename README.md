**全8章・33単元 ＋ ハンズオン6本 ＋ 最終課題**　｜　目安：50〜70時間 ＋ 最終課題

## 進め方

1. [CURRICULUM.md](./CURRICULUM.md) の順に、単元ファイルを読む（【概念の解説】→【実務・ビジネスとの結びつき】）
2. 【理解度チェック課題】【顧客向け言語化トレーニング】に、`answers/` のテンプレートで回答する
3. 回答を講師（Claude）に送る（ファイルの内容を貼り付ける、または GitHub 上のファイルを指定する）
4. 採点・フィードバックを受け、`answers/` のフィードバック欄に反映する
5. CURRICULUM.md のチェックボックスを `[x]` にしてコミットし、次の単元へ

> 【顧客向け言語化トレーニング】の「💡 回答のヒント」は、**自分で回答を書いてから**開いてください。
> 第8章のロールプレイは、チャットで講師（Claude）が顧客役を務めます。

### ハンズオンの環境（MacBook 前提）

ハンズオンは **MacBook（macOS、Apple シリコン / Intel どちらも可）** を前提にしています。**最初に [SETUP-MAC.md](./SETUP-MAC.md) の手順で環境を整えてください**（30〜60分）。

| 必要なもの | 使う章 | 入れ方 |
|---|---|---|
| Homebrew・Git・GitHub CLI | 全章 | [SETUP-MAC.md](./SETUP-MAC.md) 手順2・3・5 |
| Docker Desktop for Mac | 第1・3・4・5章 | [SETUP-MAC.md](./SETUP-MAC.md) 手順4 |
| VS Code | 全章 | [SETUP-MAC.md](./SETUP-MAC.md) 手順6 |
| ネットワークコマンド（dig / curl / openssl / nc / traceroute） | 第2章 | macOS に標準で入っている |
| Google アカウント（BigQuery サンドボックス・Looker Studio。**クレジットカード不要**） | 第6章 | ブラウザだけで利用 |

ハンズオンのコードは**学習専用**です。パスワード等は学習用の値を使っており、インターネットに公開しない前提で作られています。

## 受講者プロフィール（開始時点）

- **背景**：プログラミングスクール講師（教える・概念を整理する土台あり）
- **できること**：PHP / Laravel の基礎構文、SQL の初歩（SELECT, WHERE）
- **これから身につける領域**：ハードウェア・OS の動作原理、ネットワーク、RDB の本格的な設計と堅牢化、多層セキュリティ、BigQuery とデータパイプライン、顧客への提案

## 学習完了の定義（ゴール）

1. コンピューターとインターネットの基礎から「**なぜセキュリティ侵害が起きるのか**」を根本原理から説明できる
2. SaaS や Excel の分散データを正規化し、堅牢な自社 RDB（PostgreSQL）へ**安全に取り込む設計・構築**ができる
3. 自社 RDB から BigQuery へデータを流し込み、**分析用テーブル設計とダッシュボード可視化**ができる
4. 非エンジニアの経営者・担当者に対し、「**自社 DB 化と BigQuery 導入のメリット・安全性・ROI**」を噛み砕いてプレゼン・質疑応答できる

# 中小企業向けデータ基盤構築 実践カリキュラム

> Excel・SaaS（kintone / HubSpot 等）に散らばった業務データを、**現場の業務を壊さずに**自社専有の堅牢なデータベースへ集約し、**BigQuery で全社分析・可視化**できる基盤を提案・構築できるようになるための教材です。

---

## このリポジトリの使い方

| ファイル / フォルダ | 中身 |
|---|---|
| [`CURRICULUM.md`](./CURRICULUM.md) | カリキュラム全体像・微調整案・進捗チェックリスト |
| [`chapter-01/`](./chapter-01/) 〜 | 各章の単元教材（1単元 = 1ファイル） |
| [`answers/`](./answers/) | 受講者の回答とフィードバックの記録 |

### 進め方

1. 単元ファイルを読む（【概念の解説】→【実務・ビジネスとの結びつき】）
2. 【理解度チェック課題】【顧客向け言語化トレーニング】に回答する
   - 回答は `answers/chapter-XX/XX.md` のテンプレートに書く
3. 講師（Claude）が採点・フィードバック → `answers/` に追記
4. `CURRICULUM.md` のチェックボックスを更新し、次の単元へ

> 一度に全部を出さず、**1単元ずつ**進める方針です。

## 受講者プロフィール（開始時点）

- **背景**: プログラミングスクール講師（教える・概念を整理する土台あり）
- **できること**: PHP / Laravel の基礎構文、SQL の初歩（SELECT, WHERE）
- **これから身につける領域**
  - コンピューターのハードウェア構造・OS の動作原理
  - インターネット・ネットワークの仕組み（TCP/IP、DNS、ルーティング等）
  - RDB の本格的な論理・物理設計、トランザクション、堅牢化
  - サーバー・Web・API・クラウド・DB にまたがる多層セキュリティ
  - BigQuery（DWH）の立ち上げ、データパイプライン（ETL/ELT）、Looker Studio 連携

## 学習完了の定義（ゴール）

1. コンピューターとインターネットの基礎から「**なぜセキュリティ侵害が起きるのか**」を根本原理から説明できる
2. SaaS や Excel の分散データを正規化し、堅牢な自社 RDB（PostgreSQL）へ**安全に取り込む設計・構築**ができる
3. 自社 RDB から BigQuery へデータを流し込み、**分析用テーブル設計とダッシュボード可視化**ができる
4. 非エンジニアの経営者・担当者に対し、「**自社 DB 化と BigQuery 導入のメリット・安全性・ROI**」を噛み砕いてプレゼン・質疑応答できる

## 各単元のフォーマット

| セクション | 目的 |
|---|---|
| 【概念の解説】 | ハードウェア・OS・パケット・DB エンジンの**物理的な動き**がイメージできるように解説 |

| 【顧客向け言語化トレーニング】 | 非エンジニアの経営者からの質問に、専門用語なしで答える演習 |
